🤖 Will I get Native Android Notifications?

Yes! HydroFlow uses the Service Worker Notification API (showNotification) with vibration patterns ([200, 100, 200]), which Android Chrome requires to post real notifications in your phone's top status bar.

  • Hosted on HTTPS / Installed PWA: When you open this HTML file via an https:// link (e.g., GitHub Pages, Netlify, Vercel) or localhost in Android Chrome and tap "Add to Home Screen", you get native Android system tray notifications and one-click Chrome installation.
  • Keep App Open or Pinned: Because pure client-side web apps run without an external cloud push server, timers fire reliably while the app is open or running in the background on Android.
